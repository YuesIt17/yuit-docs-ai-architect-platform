# ADR-003: Graph Database

## Decision
**Neo4j Community** for GraphRAG ontology: Document, Chunk, Entity, Topic, LabelAsset.  
Edges: CONTAINS, REFERENCES, ABOUT, AMENDS, HAS_ALLERGEN, GOVERNS, EXTRACTED_FROM, DESCRIBES_SKU.

MVP: in-memory graph mirroring the same model; compose Neo4j for Browser demo.
