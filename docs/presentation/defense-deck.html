Зачем платформа

Какие задачи решает платформа

Найти правило. Проверить источник. Не раскрыть закрытые данные.

Проблема

RISK
Ответы без опоры на документы HIGH
Политики, НПА и этикетки разрознены: модель может сформулировать требование, которого нет в источниках. Качество пересказа оценивается отдельно от ACL.
Закрытые promo/margin HIGH
Сотрудник без допуска не должен увидеть секретный playbook в ответе и в списке источников.
Внешняя облачная модель BLOCK
Отправка внутренних документов во внешний API недопустима для выбранного сценария. Нужен локальный serving.

Решение

RESPONSE
Поиск по связям и фрагментам GRAPH+VEC
Сначала связи товар → аллерген → правило, затем текстовые фрагменты документов. Ответ сопровождается источниками.
Фильтр доступа до модели ACL
Роль ограничивает доступные документы. Смотрим ответ и citations, а не только badge allow/deny.
Локальная модель OLLAMA
На демо — Ollama на CPU. Self-hosted inference не доказывает полный air-gap сети; изоляция проверяется отдельно.

Из чего состоит

Из чего состоит платформа

УПРАВЛЕНИЕ ЗАПРОСОМ
LangGraph + проверки доступа
Задаёт шаги обработки и условные переходы. Проверки на входе/выходе и фильтр доступных документов — до генерации ответа.
СВЯЗИ
Neo4j
Хранит связи предметной области: товар, аллерген, правило. Помогает найти нужные документы по структуре знаний.
ФРАГМЕНТЫ ТЕКСТА
Qdrant
Ищет текстовые куски документов среди уже доступных роли источников.
ОТВЕТ
Локальная модель (Ollama)
Пишет ответ по собранному контексту. На демо — qwen2.5:0.5b. Профиль сдачи vLLM+AWQ на GPU не проверен.
НАБЛЮДАЕМОСТЬ
Grafana + Prometheus + Tempo
Метрики снимает Prometheus с HTTP /metrics (~15 с). Трассы: OTLP → Tempo. Логи — отдельный путь в Loki.
ВТОРОСТЕПЕННО
Redis · MinIO
Кэш готовых ответов (с учётом роли) и объектное хранилище для файлов/экспортов. Не центр демо-сюжета.

Control Plane: API + LangGraph + проверки. Data Plane: хранилища и model serving. Размещение — на следующем слайде.
